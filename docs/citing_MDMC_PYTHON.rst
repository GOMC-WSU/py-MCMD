Citing py-MCMD
==============

When py-MCMD contributes to published work, cite the software release used and
the py-MCMD paper. Cite CatDCD as well when it is used to combine trajectories.

py-MCMD paper
-------------

M. Soroush Barhaghi, B. Crawford, G. Schwing, D. J. Hardy, J. E. Stone,
L. Schwiebert, J. Potoff, and E. Tajkhorshid, *py-MCMD: Python Software for
Performing Hybrid Monte Carlo/Molecular Dynamics Simulations with GOMC and
NAMD*, Journal of Chemical Theory and Computation **2022**, 18 (8), 4983-4994.
`DOI: 10.1021/acs.jctc.1c00911 <https://doi.org/10.1021/acs.jctc.1c00911>`_.

Software release
----------------

Cite the archived release that was used for the calculation. The initial
release is available at `Zenodo <https://doi.org/10.5281/zenodo.5142483>`_. The
current source is maintained at the
`py-MCMD repository <https://github.com/GOMC-WSU/py-MCMD>`_.

CatDCD
------

When CatDCD is used, cite J. Gullingsrud, *CatDCD -- Concatenate DCD files*,
version 4.0 (2009), `Theoretical and Computational Biophysics Group
<https://www.ks.uiuc.edu/Development/MDTools/catdcd/>`_.
